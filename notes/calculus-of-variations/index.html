Calculus of variations · Interactive note 01

Shake a function,
not a number.

Ordinary calculus asks what happens when a number moves a little. Calculus of variations asks what happens when an entire function changes shape.

ya(x) = y0(x) + a η(x)

The central move

Replace a tiny step with a tiny reshaping.

A functional is a rule that takes a whole function as its input and returns one number. Here that number is the length of a curve between x = −1 and x = 1:

J[y] = ∫−11 √(1 + y′(x)2) dx

To test a curve y0, we add a small variation aη(x). The variation vanishes at both endpoints, so the endpoints stay fixed while the middle of the curve “shakes.”

What this means

A stationary function feels flat in every direction.

01

Choose a trial function

Start with y0(x). A function is now the “point” whose neighborhood we want to inspect.

02

Choose a direction

η(x) is one direction in function space. Multiplying it by a controls how far we move.

03

Watch the functional

If the first-order change vanishes for every allowed η, the function is stationary: δJ = 0.

Takeaway

Calculus of variations is ordinary calculus performed on a space whose points are entire functions.

This experiment uses arc length because it is visible. The same idea produces geodesics, Fermat’s principle, the Euler–Lagrange equation, and the principle of stationary action.
