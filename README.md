# SepoPark.github.io

Personal research website for Joseph Park, focused on theoretical physics,
mathematics, and computational science.

The site is intentionally build-free: GitHub Pages serves `index.html` and the
local assets directly.

Interactive notes are ordinary pages inside `notes/`. The first example,
`notes/calculus-of-variations/`, visualizes a function variation and the
arc-length functional without external libraries.

## Preview locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
